# PM_Assistant 功能测试报告
- 项目版本：V1.0

- 测试类型：浏览器端全链路功能验证

## 1. 测试环境与配置
### 1.1 运行环境
- 运行方式：本地 Streamlit 服务 + 真实浏览器端到端验证
- 操作系统：Linux 沙箱环境
- 依赖版本：Python 3.9+，Streamlit >=1.35，SQLAlchemy 2.0.52

### 1.2 模型配置
| 模块 | 模型 | 服务商 |
|---|---|---|
| 对话生成 | deepseek-v4-pro | DeepSeek |
| Embedding 向量 | text-embedding-v4 | 阿里云通义千问 |
| Rerank 重排 | rerank | 智谱AI |
| 自审模型 | qwen3.8-max | 阿里云通义千问 |

### 1.3 RAG 链路配置
- 分块策略：结构感知分块，chunk_size=700，chunk_overlap=100
- 检索链路：向量语义检索 + BM25 关键词检索 → RRF 融合 → Rerank 精排
- 候选数量：Rerank 输入 20 条，最终输出 Top-K=5
- 知识库预置文档：《产品需求文档.md》

## 2. 测试范围
本次测试覆盖以下核心能力域：
1. 多助手对话与角色切换
2. 结构化内容生成（方案、PRD、风险分析、汇报材料）
3. RAG 知识库混合检索与来源引用
4. Agent 跨模型自审机制
5. PPT / Word 文档生成与导出
6. 无密钥异常容错

## 6. 已知限制与说明
### 6.1 Review 自审结果持久化说明
正常执行成功时，Reviewer 结果会加入当前助手消息，并随话题数据写入 `history_topics.json`；页面重新加载后可从历史消息中恢复展示。
Reviewer 调用失败或回答流程发生异常回滚时，不产生可持久化的 review 记录。

### 6.2 办公文档边界限制
- PPT 编辑：暂不支持 SmartArt 图形修改；含动画的 PPT 编辑后动画可能丢失或异常
- Word 编辑：含修订标记的 DOCX 编辑后，修订历史可能被破坏
- 所有编辑操作均输出副本，不覆盖源文件

### 6.3 其他限制
- 知识库单文件建议不超过 5MB；
- Project Memory 当前为单项目模式，不支持多项目复杂管理；
- 事实抽取依赖大模型质量，设计为人工确认后入库，避免误判。

## 7. 测试结论
本次13条浏览器端全链路功能测试全部通过，核心功能链路运行稳定。
- 对话生成、RAG 混合检索、跨模型自审、文档导出四大主干功能验证可用；
- 异常容错与降级机制符合设计预期，无密钥、无数据库场景下均安全降级；
- 自审结果持久化逻辑正常，异常场景回滚机制符合设计；
- 输出具备政务场景适配性，诚实性约束生效，无资料时不编造。

本报告仅验证**功能可用性**，不代表 AI 输出质量与效果已完成量化验证。AI 效果对照实验详见 `agent_eval_report.md`。
